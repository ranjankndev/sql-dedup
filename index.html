Find duplicate SQL patterns in your NL → SQL dataset

Many queries in a text-to-SQL dataset have the same structure. Only the values or the table and column names are different. These duplicates do not improve the training. This tool finds them and gives you a file with only the unique patterns.

🔒 The tool runs in your browser. Your file does not go to a server.
What the tool does

Compares the SQL structure, not the text

The tool parses each query and changes it to a standard form. Two queries with the same standard form are duplicates. The tool keeps the first query and marks the others.

  • exact: spaces, letter case and comments are ignored.
  • template: values are also ignored.
  • skeleton: table and column names are also ignored.
Input

A file of question + SQL pairs

Use one of these:

  • .json: an array of objects
  • .jsonl: one object on each line
  • .csv: one row for each pair
  • Or paste only the SQL queries.

Field names are found automatically. SQL: sql, query, SQL, gold_sql … Question: question, nl, instruction …

{"question": "Customers older than 30",
 "sql": "SELECT name FROM customers WHERE age > 30"}
Expected output

A report and a clean file

  • The number of pairs, unique patterns and duplicates.
  • The duplicate rate at each of the three levels.
  • Each pattern group, with the kept query and its duplicates.
  • Download: the unique pairs in the same format as your file.
  • Download: a JSON report of the duplicate groups.

Try it

Select a sample, upload a file or paste SQL. Then click Find duplicates.

Put a ; after each query. If there is no ;, the tool uses one line for each query.
